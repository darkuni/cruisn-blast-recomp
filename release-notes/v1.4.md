Native Windows and Steam Deck / Linux build of Cruis'n Blast (Nintendo Switch, Raw Thrills 2021, v2.0.0), statically recompiled. Not an emulator.

**New in v1.4**
- PlayStation 5 DualSense, DualSense Edge and PlayStation 4 DualShock 4 are now read directly (USB or Bluetooth), the way Steam and SDL do. In v1.3 Windows did not report a DualSense to the game on some PCs, so it did nothing. Rumble on these by USB.
- Turn Steam Input off for the game (or close Steam) so the game sees the controller itself.
- `cruisn-blast.log` now always says which controller was found and how (for example "DualSense (054c:0ce6) by USB, read directly"), or that none was. If your controller still does nothing, please send that log in.

**From v1.3**
- Switch Pro, 8BitDo and other gamepads work on Windows; with several connected, the one you last pressed is used.
- Rumble on those controllers too, where Windows or Linux supports it (before, only Xbox pads rumbled, and nothing on Linux).
- More diagnostics for the lighting bug in `cruisn-blast-gpu-diagnostics.bat` (F5, F9, F10; see README.txt). They do nothing in normal play.

Known: the lighting blows out (too bright) in races 3 and 4 of a four-race circuit; the same tracks raced on their own look right. The FINISH banner can look wrong at the end of a race. Being worked on.

**No game files or game code included** - you need your own dump from your own Switch: the base NSP (0100B41013C82000), the v2.0.0 update NSP (0100B41013C82800) and `prod.keys`.

1. Download `CruisnBlast-windows.zip` (or `CruisnBlast-linux.tar.xz` for Steam Deck / Linux) and unpack it.
2. Drag the two NSPs and `prod.keys` onto `setup.exe` (Linux: `./setup <files>`). About five minutes: it writes the `game` folder and the shader file, then builds the game. Nothing else to install.
3. Run `cruisn-blast.exe`. Needs a Vulkan 1.3 GPU; Windows 10/11 64-bit or SteamOS / Linux.

Updating: unpack over your folder (let the copy finish) and run `setup.exe` again; it keeps the game data and only rebuilds the game.

Your player name: `name =` under `[player]` in `cruisn-blast.ini`. F1 / Esc (Start + Back): settings. F11: fullscreen. Controls are in README.txt.
