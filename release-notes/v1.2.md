Native Windows and Steam Deck / Linux build of Cruis'n Blast (Nintendo Switch, Raw Thrills 2021, v2.0.0), statically recompiled. Not an emulator.

**New in v1.2**
- Fixed: the game crashed ("graphics driver stopped responding") during the rainy race. The shader translator read the wrong half of a 16-bit value in the wet-road shader, so a loop could run billions of times.
- If the graphics driver ever stops the GPU again, the game now closes with a message instead of vanishing, and `cruisn-blast.log` says what the GPU was drawing. For a fuller report, start the game with `cruisn-blast-gpu-diagnostics.bat` (Linux: `KIRIKAE_GPU_DIAG=1 ./cruisn-blast-linux.sh`) and send that log.

Known: lighting is too bright in some races (blown-out glow), and the checkered flag at the end-of-race ceremony looks wrong. Being worked on.

**No game files or game code included** - you need your own dump from your own Switch: the base NSP (0100B41013C82000), the v2.0.0 update NSP (0100B41013C82800) and `prod.keys`.

1. Download `CruisnBlast-windows.zip` (or `CruisnBlast-linux.tar.xz` for Steam Deck / Linux) and unpack it.
2. Drag the two NSPs and `prod.keys` onto `setup.exe` (Linux: `./setup <files>`). About five minutes: it writes the `game` folder and the shader file, then builds the game. Nothing else to install.
3. Run `cruisn-blast.exe`. Needs a Vulkan 1.3 GPU; Windows 10/11 64-bit or SteamOS / Linux.

Updating: unpack over your folder (let the copy finish) and run `setup.exe` again; it keeps the game data and only rebuilds the game.

Your player name: `name =` under `[player]` in `cruisn-blast.ini`. F1 / Esc (Start + Back): settings. F11: fullscreen. Controls are in README.txt.
